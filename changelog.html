20260709_0621 earlytesting Firmware 1000T-F103VC · 2000H-F103VB · 2000H-F103VC · 2000T-F103VC · 3000T-F103VC · 4000H-F103VB · 4000H-F103VC · 4000H2-F103ZE · 4000T-F103VC · SNAP2-F103VC · SNAP4-F103VC 2026-07-09

Critical firmware fixes - update recommended for ALL boards:

Cabinets with a SpecVision attached could hang at power-on and look stuck in a boot loop: after display init the I2C bus ran far above its 25 kHz design speed, and a bus error could freeze the controller entirely. The bus now stays at its intended speed, display interrupts can no longer starve the system, and the controller recovers automatically within 100 ms if the display link ever locks up.

The DISS (Disconnect/Keyboard) input on all boards except the 4000H2 was electrically floating - boards with nothing wired to DISS could randomly enter keyboard mode or reboot repeatedly. The input now has its pull-up enabled, matching every other mode input.

Boards with the F103VB chip (some 2000H/4000H) update with the in-app ST-Link flasher; everything else updates in-app over USB.

20260708_0500 earlytesting Linux / Batocera 2026-07-07

First PactoLink release for Linux emulation systems: Batocera, RetroPie, Lakka and desktop Linux.

Mode changes pop right on the cabinet screen (PC Batocera) or as RetroArch messages in-game, and the full Pacto configurator is served to any browser on your network at http://<cabinet-ip>:46810. Keyboard/Disconnect mode works out of the box for MAME-style play; native gamepad (XInput) support on Linux arrives with the upcoming "Linux mode" firmware update: switch the board's USB identity to Linux mode and Linux's own built-in Xbox-pad driver runs the controls directly.

One-line install on any of them: curl -L https://raw.githubusercontent.com/leecyrille/PactoTech_Public_Releases/main/install.sh | sh (RetroPie/desktop Linux: | sudo sh) - the script detects your system and installs the right signed package; the releases README has step-by-step instructions including how to open a terminal or SSH in. Batocera can also install with no terminal at all: drop the zip contents on the cabinet's share and launch "Install PactoLink" from the Ports menu. Raspberry Pi (aarch64) builds are included but still experimental. See the Help section in the app or web configurator for step-by-step guides.
