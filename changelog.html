Updates for the Pacto Tech Utility app and controller firmware.

20260710_0500 earlytesting App 2026-07-09

In-game overlays now show over fullscreen games. Games running in exclusive fullscreen (MAME's default on Windows) used to hide the mode-change banners entirely, because Windows won't let any other window draw over an exclusive-fullscreen game. The Utility now draws the banner inside the game's own picture, so it shows over any fullscreen game - the same technique the Steam and Discord overlays use. It's on by default (App Options -> "Draw banners over fullscreen games"). Note: because this works by drawing into the game, some antivirus tools may flag the Utility; if that happens you can turn it off there and use the per-emulator options instead. For MAME you can install a small plugin (App Options -> Install MAME plugin) and RetroArch shows the banners once its Network Commands are enabled - neither of those needs the in-game overlay.

Clearer firmware-update messages: boards with the 128 KB F103VB chip (some 2000H and 4000H boards) now say plainly that they update with the ST-Link flasher - this is normal for that chip, not a one-time step and not old firmware - and the Update page names your exact chip (for example "4000H (F103VB)"). A misleading "already updates from the app" note has been removed for boards that actually need the ST-Link.

Critical firmware fixes - update recommended for ALL boards:

Cabinets with a SpecVision attached could hang at power-on and look stuck in a boot loop: after display init the I2C bus ran far above its 25 kHz design speed, and a bus error could freeze the controller entirely. The bus now stays at its intended speed, display interrupts can no longer starve the system, and the controller recovers automatically within 100 ms if the display link ever locks up.

The DISS (Disconnect/Keyboard) input on all boards except the 4000H2 was electrically floating - boards with nothing wired to DISS could randomly enter keyboard mode or reboot repeatedly. The input now has its pull-up enabled, matching every other mode input.

Boards with the F103VB chip (some 2000H/4000H) update with the in-app ST-Link flasher; everything else updates in-app over USB.

20260708_0500 earlytesting Linux / Batocera 2026-07-07

First PactoLink release for Linux emulation systems: Batocera, RetroPie, Lakka and desktop Linux.

Mode changes pop right on the cabinet screen (PC Batocera) or as RetroArch messages in-game, and the full Pacto configurator is served to any browser on your network at http://<cabinet-ip>:46810. Keyboard/Disconnect mode works out of the box for MAME-style play; native gamepad (XInput) support on Linux arrives with the upcoming "Linux mode" firmware update: switch the board's USB identity to Linux mode and Linux's own built-in Xbox-pad driver runs the controls directly.

One-line install on any of them: curl -L https://raw.githubusercontent.com/leecyrille/PactoTech_Public_Releases/main/install.sh | sh (RetroPie/desktop Linux: | sudo sh) - the script detects your system and installs the right signed package; the releases README has step-by-step instructions including how to open a terminal or SSH in. Batocera can also install with no terminal at all: drop the zip contents on the cabinet's share and launch "Install PactoLink" from the Ports menu. Raspberry Pi (aarch64) builds are included but still experimental. See the Help section in the app or web configurator for step-by-step guides.

Fixes from early testing feedback.

Flashing with ST-Link is more resilient: if the chip can't be reached, the Utility keeps retrying with clear guidance - check the wiring, make sure the board has its own power, and power-cycle it. Detect once, then flash - no extra tools needed.

20260707_0419 earlytesting App 2026-07-06

The Utility can now flash boards with an ST-Link, right from the app.

If your board is on firmware from before in-app updates existed (or has the F103VB chip), you no longer need any external flashing tools: connect an ST-Link V2 to the board's SWD header, pick your board model in the Utility's firmware section, and press Flash. The app reads the chip itself, downloads the matching signed image, and refuses anything that doesn't fit your exact hardware.

Also fixes update-signature verification for in-app firmware updates.

20260707_0353 earlytesting App + Firmware 1000T-F103VC · 2000H-F103VB · 2000H-F103VC · 2000T-F103VC · 3000T-F103VC · 4000H-F103VB · 4000H-F103VC · 4000H2-F103ZE · 4000T-F103VC · SNAP2-F103VC · SNAP4-F103VC 2026-07-06

First Early Testing release of the new Pacto Tech software platform.

The Pacto Tech Utility for Windows: live controller status and input testing, full remapping for XInput and keyboard outputs, mode controls with editable shortcuts, customizable on-screen overlays and themes, kiosk/lockdown modes for cabinets, ready-made scripts for LaunchBox and other frontends, and automatic app updates on your chosen channel.

New firmware for every current board (1000T, 2000T, 2000H, 3000T, 4000T, 4000H, 4000H2, SNAP2, SNAP4 - including the F103VB chip variants of the 2000H/4000H and the F103ZE-based 4000H2) introduces in-app firmware updates: flash your board once with the matching ST-Link image from this release, and every update after that installs from inside the Utility with a couple of clicks. Updates are checked against your exact board model AND its chip, an interrupted update can't brick the board, and a file for the wrong board simply won't apply. Boards with the smaller F103VB chip keep updating via ST-Link (no room for the update system on that chip) - the Utility tells you when a new version is out for them.

Also improved: much cleaner switching between arcade (XInput) and gamepad/keyboard (DISS.) modes, per-input mode settings, twin-stick 1P/2P modes, and turbo refinements.
