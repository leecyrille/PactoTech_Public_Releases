Pinball Inputs

Choose what each pinball input sends to the PC (a button, an instant stick push or a gradual one) and try it out on a live pinball table.

Pinball Inputs is in the Controller group of the sidebar: its settings are stored on the board when you press Save to controller.

The status line

The line under the page title always tells you where you stand:

  • No controller connected: it asks you to connect one.
  • Nothing feeds any pinball input (for example a 4000T, which has no pinball pins, before anything is mapped): it says so, the rows are greyed out, and it explains how to use spare inputs, with an Open Default XInput Mapping button (and, on boards without pinball pins, an Open Wiring & Hardware button).
  • Some inputs are fed: it lists them, split into board pins and mapped player buttons. Rows with nothing feeding them stay dimmed, each with a note saying nothing on the board produces that input yet.

Pinball on a board without pinball pins

This is only possible if you can spare inputs for it, because each pinball input borrows one of the board's existing inputs. Spare inputs can be:

  • Player buttons no game on the cabinet needs, for example Player 3 and 4 on a 2-player panel.
  • Mode inputs you don't use (mode switches, turbo or 8-to-6 inputs). Free them under Mode input wiring on Wiring & Hardware, then give each one a player-input slot under Spare pins as player buttons on the same page.

Then, on Default XInput Mapping, go to Buttons that trigger modes and pinball inputs, press Add mapping, choose the spare input and pick one of the PINBALL: functions (Nudge Left, Nudge Right, Left Flipper, Right Flipper, Launch / Plunger, Nudge Up). If your controller's firmware supports it, also tick Stop game output on that row, so the borrowed button no longer sends its own button to games. Press Save to controller; the Pinball Inputs page then unlocks that row.

Without Stop game output (or on older firmware, where that tick box is hidden), a borrowed input still sends its normal game output as well, so only use inputs nothing else needs.

Nudge Up doesn't have its own pin. Press Nudge Left and Nudge Right together and the board treats it as Nudge Up.

Pinball outputs always go to Player 1's controller.

The input rows

There is one row for each of the six pinball inputs: Nudge Left, Nudge Right, Left Flipper, Right Flipper, Launch / Plunger and Nudge Up. Each row has the same controls.

ControlWhat it does
D-PAD · ANALOG FAST · ANALOG SLOW How the input behaves. D-PAD acts as a button, ANALOG FAST gives an instant full analog push, and ANALOG SLOW gives a timed ramp using the ramp times below.
Output What the input sends. The choices are:
  • Disabled (the input does nothing)
  • a button: START, BACK, LS (stick click), RS (stick click), LB, RB, GUIDE, A, B, X or Y
  • a D-pad direction: DPAD Up Fixed … DPAD Right Fixed
  • a left-stick direction: L-Ana Up Fixed … L-Ana Right Fixed
  • a right-stick direction: R-Ana Up Fixed … R-Ana Right Fixed
  • a trigger: LT or RT
Ramp up / Ramp down (ms) For ANALOG SLOW: how long the push takes to build to full (Ramp up) and to die away after you let go (Ramp down), from 0 to 2000 ms. In the other two modes these boxes are dimmed and marked ramps apply in ANALOG SLOW.

The mode only makes a difference when the output is a stick direction (L-Ana / R-Ana) or a trigger (LT / RT). Buttons and D-pad directions are simply pressed for as long as you hold the input.

Unlike the Analog Slow joystick mode (on the Modes page), a pinball ramp starts from zero, so a slow nudge really does build up from nothing.

Set Launch / Plunger to R-Ana Down Fixed with ANALOG SLOW for a realistic, progressive plunger pull.

Want a different nudge feel for one table or pinball program? Set Nudge speed in its game profile instead of changing this page.

Live table

Press your pinball inputs and the drawing reacts exactly as configured, including slow-ramp nudges. Nudges shove the table and light up that side, the flippers flip, the plunger pulls back, and the name of each input flashes in the middle as you press it. The table follows the settings currently on the page, even before you save them, so you can try changes first.

Saving and restoring

  • Save to controller writes all six rows to the board and stores them there.
  • Restore Pinball Defaults puts every row back to the defaults above. Press Save to controller afterwards to keep them.
  • If you switch pages with unsaved changes, the Utility asks whether to Save or Discard them.
